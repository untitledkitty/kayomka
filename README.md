# 🎨 Сайт-визитка художника

Современный и адаптивный сайт-визитка, разработанный для демонстрации портфолио, творческого стиля и контактной информации художника. Главный фокус проекта — эстетичный дизайн, плавная анимация и удобный интерфейс.

## 🛠️ Используемые технологии

В проекте использованы классические технологии веб-разработки без сторонних тяжелых фреймворков, что обеспечивает максимальную скорость загрузки:

* **HTML5** — семантическая структура и разметка контента.
* **CSS3** — стилизация, кастомные переменные и адаптивная верстка.
* **JavaScript (Vanilla JS)** — интерактивные элементы, оживление галереи и обработка пользовательских событий.
* **Git / GitHub** — контроль версий и хостинг проекта.

### 📐 Особенности верстки и CSS
* **CSS Grid** — используется для создания эффектной сетки галереи (портфолио) с возможностью динамического расположения работ разного формата.
* **CSS Flexbox** — применен для построения навигации (шапки сайта), позиционирования элементов внутри карточек и выравнивания контента.
* **Адаптивный дизайн** — сайт корректно отображается на любых устройствах: от мобильных телефонов до больших мониторов.

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/untitledkitty/govno.git
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```
3. Откройте файл `index.html` в любом браузере.
